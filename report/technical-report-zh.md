# Common Ground / Leeds——补充技术报告

**项目网址：** https://opalus12138.github.io/chen/
**模块：** GEOG5870 基于 Web 的 GIS
**字数说明：** 中文字符约 2,100 个

## 1. 项目要解决的问题

Common Ground / Leeds 是一张展示利兹公共绿地记录情况的探索性地图。我选择这个题目，是因为地点清单很难说明绿地在城市中的分布。通过地图，访客可以先看整体格局，再搜索某个地点、比较绿地类型，并查看记录面积最大的空间。网站面向普通访客，不要求使用者具备 GIS 软件经验。

这张地图不能当作可达性或健康状况地图来读。一个多边形只能说明某个地点出现在数据中，不能说明入口是否方便、场地维护得怎样，或者从某个住址步行过去需要多长时间。我在网站中保留了这一区分，没有把数据解释成它无法支持的结论。

## 2. 需求与使用场景

作业简报要求使用 HTML、CSS、JavaScript 和 Leaflet 构建一个可以工作的地图网站，并用文字说明相关地理问题和数据来源。我把它转化成一个简单的使用流程：访客应能理解地图要回答的问题，在城市尺度查看利兹，搜索一个绿地名称，按类型筛选，并查看某个地点的属性，而不需要打开单独的 GIS 软件。

页面包含项目介绍、可搜索的 Leaflet 地图、分类选择器、弹窗、重置按钮和三个实时统计数字。地图下方还有类别图表和记录面积最大的五个绿地列表。这两个部分不是静态装饰：点击类别后会筛选地图，点击排名中的地点后，地图会移动到该位置、高亮空间并打开弹窗。“Types”和“Area”两个按钮提供同一数据层的两种读法。前者使用统一颜色，后者使用深浅不同的绿色表示记录面积区间。

我还加入了数据来源、局限性说明、键盘焦点样式、响应式布局和减少动画规则。如果数据请求失败，地图会显示简短的错误提示，不会只留下一个空白区域。

## 3. 数据与处理

数据来自 Leeds City Council 的 Public Green Spaces ArcGIS REST 要素服务。该服务每次最多返回 1,000 条记录，因此我使用两次分页请求获取了完整的 1,781 条记录。请求时将几何数据转换成 WGS84，这也是 Leaflet 直接使用的坐标系。

本地 GeoJSON 保留网站真正需要的字段，包括地点名称、来源编号、行政区域、记录面积、所有权和维护信息。原始类型字段使用缩写编码，我先查看服务的字段元数据，再将编码转换为 “Local park”“Allotment” 和 “Natural and semi-natural” 等可读名称。我没有根据地点名称猜测类别；可选信息缺失时，界面会显示 “Not available”。

浏览器只加载一次本地数据文件。JavaScript 保存完整地点列表，并根据分类和搜索文字生成当前结果。筛选条件变化后，Leaflet 重新绘制可见空间，旁边的统计数字也使用同一份筛选结果重新计算。这样，地图旁边的数字始终对应访客当前看到的内容。

“Area”模式使用三个记录面积区间：小于 5 公顷、5 至 20 公顷和超过 20 公顷。缺少面积的空间使用浅色显示。记录面积最大的五个多边形会在地图上显示编号，并出现在下方排名中。地图标记和列表使用相同的来源编号，因此两处信息保持对应。

## 4. 技术与设计选择

我使用语义化 HTML 组织标题、标签、列表和页面地标。CSS 没有采用常见的后台仪表盘形式，而是使用暖米白、深绿色、少量琥珀色和大号衬线标题，做成更接近编辑版地图的页面。地图是视觉重点，控件在小屏幕上也能找到。

选择原生 JavaScript 是为了让课程要求中的编程过程清楚可见，也避免让图表库成为项目主体。Leaflet 负责底图、GeoJSON 绘制、弹窗、范围缩放和控件。网站通过 GitHub Pages 使用静态文件部署，这已经足够支持当前原型，也不需要数据库、登录系统或服务器端凭据。

项目包含基本的安全处理。弹窗文字在插入页面前会进行 HTML 转义。网站不收集访客提交的信息，仓库中没有 API 密钥。底图和 Leaflet 都通过 HTTPS 加载，并保留了来源标注。

## 5. 问题、局限性与下一步

市议会服务的单次记录限制是最主要的技术问题，最后通过分页请求解决。缩写类型编码也需要重新检查服务元数据。由于很多多边形在城市尺度下会重叠，整体地图会比较密集。筛选、透明度、面积模式和排名列表可以帮助访客减少这种密度，但没有一个缩放级别能让所有边界都同样清楚。

数据描述的是被记录下来的空间，而不是现场当前情况。它没有提供入口、步行时间、坡度、维护状况、主观安全感、使用人数，也不能保证所有区域都可以不受限制地进入。记录面积是来源数据中的属性，不能直接作为生态价值或可达性的独立指标。服务元数据没有给出单独的图层许可，因此如果继续公开分发数据，还应再次核对市议会的开放数据条款。

后续版本可以计算五分钟、十分钟和十五分钟步行范围，把绿地分布与人口和贫困数据进行比较，记录入口和设施，并显示每条数据的更新时间。增加一个可访问的数据表下载，也能让地图之外的访客使用这些信息。
